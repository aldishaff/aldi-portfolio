# Aldi Firman Saputra — Portfolio Website

Website portofolio statis responsif berbasis HTML, CSS, dan JavaScript.

## Cara menjalankan
1. Ekstrak ZIP.
2. Buka folder `aldi_portfolio_website`.
3. Klik dua kali `index.html` atau buka folder melalui VS Code dan jalankan dengan Live Server.

## Bagian website
- Hero / pengenalan
- Tentang saya
- Keahlian
- Pengalaman
- Proyek pilihan (Viva Arena, MyTookoo, Digitalisasi UMKM)
- Pendidikan
- Sertifikasi
- Kontak

## Sebelum dipublikasikan, periksa
- Tautan LinkedIn pada `index.html` masih berupa tautan umum; ganti dengan URL profil LinkedIn milik Anda.
- Pastikan kembali tahun pengalaman Staff Administrasi yang tertulis sebagai 2020 pada PDF sumber.
- Tinjau deskripsi proyek dan teknologi agar sesuai dengan kontribusi aktual.
- Jika memiliki CV terbaru, tautkan pada tombol yang sesuai atau tambahkan bagian unduhan CV.
- Nomor telepon dan email tampil secara publik pada halaman kontak. Hapus jika tidak ingin dipublikasikan.

## Struktur
- `index.html` — konten website
- `style.css` — desain responsif
- `script.js` — interaksi menu dan tahun footer
- `assets/` — foto, tangkapan layar proyek, dan sertifikat yang diekstrak dari PDF sumber
